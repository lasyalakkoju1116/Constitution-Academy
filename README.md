Sansthā — Constitution Explorer

**Meet the framers. Then watch their articles work.**

Sansthā is an interactive, single-page learning experience about the Constitution of India. It introduces key constitutional figures, explains selected articles in plain language, and uses visual simulations and short quizzes to make constitutional processes easier to explore.

> This project is an educational prototype, not legal advice or an authoritative source of constitutional text. Check the Constitution of India and current law from official sources for research or legal use.

## Features

- **Framer guide roster:** Explore Dr. B.R. Ambedkar, Jawaharlal Nehru, Sardar Vallabhbhai Patel, and Dr. Rajendra Prasad, with links to related articles.
- **Six article explorations:** Articles 1, 21, 32, 74, 108, and 368, each with plain-language explanations and an interactive activity.
- **Interactive explainers:** Follow Article 21's interpretation over time, explore Article 32's five writs, and simulate constitutional amendment paths under Article 368.
- **More constitutional simulations:** Explore princely state integration, the President's aid-and-advice process under Article 74, and a parliamentary deadlock under Article 108.
- **Knowledge checks:** Answer multiple-choice and true/false questions, receive explanations, and earn in-session XP and streaks.
- **Responsive interface:** The layout adapts to smaller screens and supports keyboard focus on interactive cards and controls.

## Run locally

This is a static website contained in one HTML file. No build step, package manager, or server-side code is required.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

The page loads Fraunces, Inter, and JetBrains Mono from Google Fonts when an internet connection is available. If those fonts cannot load, the browser uses fallback fonts.

## Deploy with GitHub Pages

1. Add the website file to the repository and name it `index.html`.
2. Push the repository to GitHub.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the branch and root folder, then save.
5. Open the Pages URL shown in the repository settings.
